# Generated MCP tool reference

Generated by `python scripts/generate_catalog.py`; no appliance calls. Catalog presence is not live availability. See [support/evidence matrix](features.md) and [write safety](writes.md).

Modes: `read` 36, `vpn` 43, `vpn+capture` 47, `combined+capture` 61.

All router operations use internal verified SSH. Read tools may expose private metadata; DNS/TCP tools generate traffic. Import preview writes a router-local journal. Capture and apply require explicit host confirmation. See each description for outputs, bounds and side effects. Existing sudo is required for kernel operations/capture and selected diagnostics; no privilege is granted by tool registration.
